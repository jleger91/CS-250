# CS-250

Projects from CS-250 class at SNHU

In order to interpret user needs, we can conduct focus groups, surveys, and encourage customer feedback. User stories is a to-do list that focuses on the needs of the customers; they are a collection of informal perspectives of a feature from the end user's point of view.

I can approach the development of programs either through the Waterfall or the Agile framework; where Waterfall is strict and depends on the mastery of requirements and a sequence of steps, Agile is adaptive and best for changing requirements. In the future i'd like to incorporate things like user stories because they better help understand and focus on the customer needs.

To be a good team member in software development depends on whether we consider Agile or Waterfall. For Waterfall, I might want to be very analytical and enjoy learning. For Agile, I want to be adaptable, flexible, able to learn new things and respond to changes regularly, and be a great team-player.
